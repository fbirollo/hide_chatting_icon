# Hide Chatting Icon for Odoo 18

This Odoo module hides the chatting icon from the top right header in the backend interface.

✅ Compatible with **Odoo 18.0**

---

## 📋 Features

- Removes the chatting icon from the systray.
- Non-intrusive: does not break any backend functionality.

---

## 📦 Installation

1. Copy the `hide_chatting_icon` folder into your Odoo `addons` directory.
2. Update the apps list in Odoo.
3. Search for **Hide Chatting Icon** in the Apps menu and install it.

Or use pip/git to clone it directly into your addons path:
```bash
git clone -b 18.0 https://github.com/YOUR_USERNAME/hide_chatting_icon.git
